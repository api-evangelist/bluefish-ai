# Bluefish AI

> Bluefish AI is an enterprise AI marketing platform built for Fortune 500 brands to gain visibility and control over how they are represented across AI channels. The platform spans AI monitoring, generative engine optimization (GEO), GEO measurement, AI brand safety and accuracy, and agentic commerce. Backed by Bloomberg Beta and Threshold Ventures, with a $43M Series B in 2026. Bluefish publishes no developer documentation, no OpenAPI, no SDKs and no llms.txt of its own — but it does operate a live, OAuth-protected remote MCP server, discovered by probe and documented below.

## Agent surface
- [MCP server](https://platform.bluefishai.com/mcp): Live remote MCP endpoint (Streamable HTTP). Requires OAuth 2.1 with the `mcp:connect` scope; an unauthenticated request returns 401 with an RFC 9728 resource_metadata challenge. Tool list is auth-gated and not published.
- [MCP vanity host](https://mcp.bluefishai.com): 301 redirects to the platform MCP endpoint above.
- [Protected resource metadata](https://platform.bluefishai.com/.well-known/oauth-protected-resource/mcp): RFC 9728 document naming the resource and its authorization server.
- [Authorization server metadata](https://auth.bluefishai.com/.well-known/oauth-authorization-server): RFC 8414 document; authorization code + refresh token + JWT bearer grants, PKCE S256, dynamic client registration.
- [OpenID Connect discovery](https://auth.bluefishai.com/.well-known/openid-configuration): OIDC discovery document, RS256 ID tokens.
- [Connected Apps](https://platform.bluefishai.com/connected-apps/authorize): OAuth authorization/consent surface, on the authenticated customer platform.
